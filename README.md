# 小明 · 个人作品集

软件工程专业在读学生的个人作品集单页网站，展示个人简介、项目作品与联系方式。聚焦 AI 辅助开发与大语言模型应用方向。

## 功能特性

- **项目作品展示**：由 `js/data.js` 数据驱动渲染项目卡片，图片加载失败时自动以渐变色占位兜底
- **深浅色主题切换**：导航栏右侧一键切换，使用 `localStorage` 记住偏好，刷新无闪烁（默认浅色）
- **平滑滚动导航**：锚点导航自动为固定头部留出偏移量
- **滚动高亮**：基于 `IntersectionObserver` 自动高亮当前所在区块
- **返回顶部**：滚动超过一屏后右下角出现
- **响应式布局**：适配桌面端与移动端（≤960px 显示汉堡菜单）

## 技术栈

- HTML5
- CSS3（CSS 自定义属性、Grid/Flex、媒体查询）
- 原生 JavaScript（ES6+，IIFE 模块化）
- 无任何前端框架、第三方 UI 库与构建工具

## 运行方式

项目为纯静态页面，无需安装依赖。

**方式一：直接打开**

双击 `index.html`，在浏览器中打开即可。

**方式二：本地静态服务器**（推荐，可完整支持主题偏好持久化）

```bash
# Python
python -m http.server 8000
```

然后浏览器访问 `http://localhost:8000`。

## 添加项目

编辑 [js/data.js](js/data.js) 中的 `PROJECTS` 数组，按现有字段（`title`、`category`、`date`、`desc`、`tech`、`image`、`link`）追加对象即可，页面会自动渲染。
