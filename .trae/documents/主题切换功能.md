# 深浅色主题切换功能实现计划

## Context（背景）

当前个人作品集网站 [index.html](file:///e:/A-GZ/KJ/LAB03/lab03/index.html) 仅有单一的浅色主题。用户希望增加深浅色主题切换，让访客可在浅色/深色间切换，并记住偏好。

**关键前提**：项目 [css/style.css](file:///e:/A-GZ/KJ/LAB03/lab03/css/style.css#L1-L9) 已使用 CSS 自定义属性（`--bg`、`--ink`、`--muted`、`--accent`、`--line`），因此采用 **CSS 变量 + `data-theme` 属性** 的最优方案，无需逐元素覆盖颜色。改动集中在变量层与少量硬编码色变量化，现有视觉风格与页面结构保持不变。

**设计决策**（采用推荐项）：
- 默认主题：浅色（首次访问无 localStorage 记录时），与当前视觉一致
- 深色色调：暖黑反转——背景 `#17150f`、文字 `#f4f1ea`，与浅色成对偶，保留品牌暖米黄色系
- 图标：Unicode 符号（☀/☾），不引入第三方库

### 2. HTML 改动（`index.html`）

#### 2.1 header 内插入主题按钮（[L17 附近](file:///e:/A-GZ/KJ/LAB03/lab03/index.html#L17)）

在 `<button class="menu-btn">` 之前插入：
```html
<button class="theme-toggle" id="themeToggle" type="button" aria-label="切换深浅色主题" title="切换主题">
  <span class="icon-sun">☀</span>
  <span class="icon-moon">☾</span>
</button>
```

为了让两个按钮在右侧并排且与左侧 brand/nav 形成 space-between 三段布局，将按钮包一层：
```html
<div class="header-actions">
  <button class="theme-toggle" ...>...</button>
  <button class="menu-btn" ...>...</button>
</div>
```
对应 CSS 给 `.header-actions { display: flex; align-items: center; gap: 0.6rem; }`。这是对现有结构的最小侵入——原 `menu-btn` 的所有样式和 ID 保持不变，只是外层多了一个容器。

#### 2.2 head 加防闪烁内联脚本（[L7 之后](file:///e:/A-GZ/KJ/LAB03/lab03/index.html#L7)）

```html
<script>
  (function(){
    try {
      if (localStorage.getItem('theme') === 'dark') {
        document.documentElement.setAttribute('data-theme', 'dark');
      }
    } catch(e){}
  })();
</script>
```
在 CSS 加载后、body 解析前同步执行，避免深色用户看到浅色闪烁。默认浅色无需设置属性。

### 3. JS 改动（`js/main.js`）

在现有 IIFE 内末尾追加（[L112 后](file:///e:/A-GZ/KJ/LAB03/lab03/js/main.js#L112)），不触碰任何现有逻辑：

```js
// 主题切换
const themeToggle = document.getElementById("themeToggle");
const docEl = document.documentElement;

function updateThemeToggle() {
  // 图标显示由 CSS 根据 data-theme 控制，这里仅同步 aria-label
  const isDark = docEl.getAttribute("data-theme") === "dark";
  themeToggle.setAttribute("aria-label", isDark ? "切换为浅色主题" : "切换为深色主题");
}
updateThemeToggle();

themeToggle.addEventListener("click", () => {
  const isDark = docEl.getAttribute("data-theme") === "dark";
  if (isDark) {
    docEl.removeAttribute("data-theme");
    try { localStorage.setItem("theme", "light"); } catch(e){}
  } else {
    docEl.setAttribute("data-theme", "dark");
    try { localStorage.setItem("theme", "dark"); } catch(e){}
  }
  updateThemeToggle();
});
```

**设计要点**：
- 浅色 = 无 `data-theme` 属性（默认态），深色 = `data-theme="dark"`。localStorage 存 `"light"` 或 `"dark"`。
- `try/catch` 包裹 localStorage（隐私模式下可能抛错，不影响主功能）。
- 图标显隐完全由 CSS 根据 `data-theme` 控制，JS 只管状态和持久化，职责清晰。
- 不引入任何新依赖，符合项目"原生 HTML/CSS/JS、不引第三方库"规则。
